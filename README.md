# Flächenlese – Web-App

Bibel-Leseplan (Große und Kleine Flächenlese) als Web-App für Android und iPhone.

## Online stellen (GitHub Pages, kostenlos)
1. Auf github.com ein neues **öffentliches** Repository anlegen, z. B. `flaechenlese`.
2. **Add file → Upload files**: alle Dateien aus diesem Ordner hochladen → **Commit changes**.
3. **Settings → Pages**: bei „Branch“ `main` und `/ (root)` wählen → **Save**.
4. Nach 1–2 Minuten ist die App erreichbar unter `https://DEIN-NAME.github.io/flaechenlese/`.

## Auf dem Handy installieren
- **Android (Chrome):** Adresse öffnen → Menü ⋮ → „App installieren“.
- **iPhone (Safari):** Adresse öffnen → Teilen → „Zum Home-Bildschirm“. Danach nur noch die App vom Home-Bildschirm benutzen.

## Daten
Alle Daten bleiben auf dem jeweiligen Gerät (kein Server, kein Konto).
Regelmäßig unter *Einstellungen → Backup speichern* sichern.

## Aktualisieren
Geänderte Dateien wieder hochladen und in `sw.js` die Versionsnummer (`flaechenlese-v1` → `v2` …) erhöhen.
