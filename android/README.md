# Flächenlese – Android-App

Schlanke Android-Hülle um die Web-App https://littlestrunziii2.github.io/flaechenlese/
mit Benachrichtigungen (morgens/abends, nur ungelesene Pläne) und Widget „Heute“.

Die APK wird automatisch von GitHub Actions gebaut (`.github/workflows/android.yml`)
und als Release veröffentlicht:
https://github.com/littlestrunziii2/flaechenlese/releases/latest/download/Flaechenlese.apk
